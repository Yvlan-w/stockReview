## 1. 测试目标与范围

### 1.1 测试目标
验证 Phase 1 重构后：

1. 页面可通过静态服务器正常加载，所有 ES 模块无脚本错误；
2. 样式组件库（tokens/base/print + 12 个组件 CSS）正确生效，视觉与原版一致；
3. 客户工作台（含顾问/客服筛选、只看预警）、持仓明细、图表、行情、策略、资讯、身份管理入口（占位）、分享导出等全部功能与交互无回归；
4. 边界条件（空数据、非法输入、重复数据、越界操作）与异常场景（外部接口不可达、存储超限、隐私模式）能被正确拦截或优雅降级；
5. 中国大陆色彩语义：所有涨/正收益显示为红色（#cf202f），跌/负收益显示为绿色（#05b169）。

## 2. 测试方法总则

每条用例均遵循以下执行与判定规范：

- **执行方式**：手动黑盒测试为主；脚本加载与运行时错误用浏览器 DevTools Console 核验。
- **步骤规范**：严格按「测试步骤」顺序操作，不得跳步；涉及弹窗/异步接口时等待页面渲染完成（默认等待 2~4 秒）。
- **预期结果**：描述操作后应呈现的界面/数据状态。
- **验收标准（关键）**：以「可通过/不可通过」二值判定；只有全部通过，该用例才算 PASS。
- **优先级**：P0 = 核心功能回归，必须全部 PASS；P1 = 重要功能；P2 = 次要/增强。

## 5. 已知环境限制与降级说明

| 场景 | 现象 | 是否产品缺陷 | 说明 |
| --- | --- | --- | --- |
| 外网无法访问东方财富接口 | 行情显示模拟数据，数据源徽章降级 | 否 | 设计内降级，环境限制；已为接口补充 `ut` token 以降低 `ERR_EMPTY_RESPONSE` 概率 |
| 外网无法访问 rss2json | 资讯显示缓存数据 + 重试按钮 | 否 | 设计内降级；`rsshub.app` 经 `rss2json` 代理可能返回 422，属第三方源波动 |
| Tailwind CDN 生产提示 | Console 出现 warn「should not be used in production」 | 否 | 仅开发期使用 CDN，Phase 2 后可选构建产物替代 |
